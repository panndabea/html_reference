1. Document Structure and Semantics

<html>
The root element of an HTML page. All other elements are descendants of this element.
Every HTML document starts and ends with <html lang="en">…</html>.
<html lang="en">
  <head>…</head>
  <body>…</body>
</html>
<head>
Contains machine-readable information (metadata) about the document — title, charset, viewport, linked styles, etc.
<head> is not visible on-page; it holds <meta>, <title>, <link>, and <style>.
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Page Title</title>
</head>
<title>
Defines the document's title shown in the browser tab and used in search results.
This page's title is: 
<title>HTML Element Reference</title>
<body>
Represents the visible content of the document. There can be only one <body>.
Everything you see on this page lives inside <body>…</body>.
<body>
  <h1>Hello World</h1>
</body>
<header>
Represents introductory content or a group of navigational aids. Typically contains a heading and site navigation.

Site Name

Tagline here

<header>
  <h1>Site Name</h1>
  <p>Tagline here</p>
</header>
<nav>
Defines a set of navigation links. Used for primary site menus and table-of-contents.
Home About Contact 
<nav aria-label="Main">
  <a href="/">Home</a>
  <a href="/about">About</a>
  <a href="/contact">Contact</a>
</nav>
<main>
Specifies the dominant content of the <body>. Must be unique in the document.
The entire reference content you're reading is inside <main>.
<main>
  <h1>Main Content</h1>
  <p>Primary content goes here.</p>
</main>
<section>
Represents a standalone section of a document that doesn't have a more specific semantic element.

About Us

We build great things.

<section>
  <h2>About Us</h2>
  <p>We build great things.</p>
</section>
<article>
Represents a self-contained composition such as a blog post, news story, or forum post.

Post Title

January 15, 2024

Article body text goes here.

<article>
  <h2>Post Title</h2>
  <time datetime="2024-01-15">January 15, 2024</time>
  <p>Article body text goes here.</p>
</article>
<aside>
Represents content tangentially related to the surrounding content — sidebars, call-out boxes, etc.
💡 Tip: Use <aside> for sidebars and supplemental content. 
<aside>
  <p>Related content or a tip goes here.</p>
</aside>
<footer>
Represents a footer for its nearest sectioning content — usually contains authorship, copyright, or related links.

© 2024 Example Site. All rights reserved.

<footer>
  <p>&copy; 2024 Example Site.</p>
</footer>
<h1> – <h6>
Six levels of section headings. <h1> is highest (most important), <h6> is lowest.

Heading 1

Heading 2

Heading 3

Heading 4

Heading 5
Heading 6
<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>
<p>
Defines a paragraph of text. Browsers automatically add margin before and after each paragraph.

This is the first paragraph. It contains some sentences to show how a paragraph is displayed.

This is the second paragraph. Notice the space between paragraphs.

<p>First paragraph.</p>
<p>Second paragraph.</p>
<hr>
Represents a thematic break between paragraphs or sections — rendered as a horizontal rule.

Content above the rule.

Content below the rule.

<p>Section one ends here.</p>
<hr />
<p>Section two begins here.</p>
<br>
Produces a line break in text. Useful for poetry or addresses.

Line one.
Line two.
Line three.

<p>Line one.<br />Line two.<br />Line three.</p>
<address>
Provides contact information for its nearest <article> or <body> ancestor.
Written by Jane Doe.
123 Main Street,
Springfield, USA. 
<address>
  Written by <a href="mailto:jane@example.com">Jane Doe</a>.<br />
  123 Main Street, Springfield, USA.
</address>

2. Text-Level Semantics

<strong>
Indicates strong importance — rendered bold by default.

Please do not press the red button.

<p>Please <strong>do not</strong> press the red button.</p>
<em>
Marks text with stress emphasis — rendered italic by default.

I really like HTML.

<p>I <em>really</em> like HTML.</p>
<b>
Draws attention to text without implying importance — rendered bold. Use <strong> for important text.

The keyword is accessibility.

<p>The keyword is <b>accessibility</b>.</p>
<i>
Represents text set off from normal prose — technical terms, foreign phrases, thoughts. Rendered italic.

The Latin phrase carpe diem means "seize the day".

<p>The Latin phrase <i>carpe diem</i> means "seize the day".</p>
<u>
Represents text with a non-textual annotation — misspelled words, proper names in Chinese. Rendered with underline.

This word is misspelled.

<p>This word is <u>mispelled</u>.</p>
<small>
Represents side comments, fine print — copyright notices, legal text.

Buy now! Offer valid while supplies last.

<p>Buy now! <small>Offer valid while supplies last.</small></p>
<mark>
Highlights text for reference or notation purposes — rendered with yellow background by default.

Search results: the term HTML was found 42 times.

<p>Search results: the term <mark>HTML</mark> was found 42 times.</p>
<del>
Represents text that has been deleted from a document — rendered with strikethrough.

Price: $99 $49

<p>Price: <del>$99</del> $49</p>
<ins>
Represents text that has been inserted into a document — rendered with underline.

The meeting is Tuesday Wednesday.

<p>The meeting is <del>Tuesday</del> <ins>Wednesday</ins>.</p>
<sub>
Specifies inline text displayed as subscript — used in chemical formulas and mathematical expressions.

Water is H2O.

<p>Water is H<sub>2</sub>O.</p>
<sup>
Specifies inline text displayed as superscript — used in exponents and footnote markers.

E = mc2

<p>E = mc<sup>2</sup></p>
<s>
Renders text with a strikethrough, indicating that it is no longer relevant (but not deleted).

Only 5 left in stock — sold out!

<p><s>Only 5 left in stock</s> — sold out!</p>
<abbr>
Represents an abbreviation or acronym. The title attribute provides the full description.

I love HTML.

<abbr title="HyperText Markup Language">HTML</abbr>
<dfn>
Marks the defining instance of a term — used when introducing a term for the first time.

A browser is software used to access the internet.

<p>A <dfn>browser</dfn> is software used to access the internet.</p>
<cite>
References a creative work — books, articles, films, etc. Rendered italic by default.

My favourite book is The Pragmatic Programmer.

<p>My favourite book is <cite>The Pragmatic Programmer</cite>.</p>
<q>
Represents a short inline quotation. Browsers add quotation marks automatically.

Tim said: The Web is for everyone.

<p>Tim said: <q cite="https://example.com">The Web is for everyone.</q></p>
<blockquote>
Represents a section quoted from another source. Use the cite attribute to link the source.

Programs must be written for people to read, and only incidentally for machines to execute.

— Harold Abelson
<blockquote cite="https://example.com">
  <p>Programs must be written for people to read…</p>
  <footer>— Harold Abelson</footer>
</blockquote>
<code>
Displays inline computer code in monospace font.

Use the document.querySelector() method to select elements.

<p>Use the <code>document.querySelector()</code> method.</p>
<samp>
Represents sample output from a computer program.

The program output was: Hello, World!

<p>Output: <samp>Hello, World!</samp></p>
<kbd>
Represents keyboard input — keys or key combinations the user should press.

Press Ctrl + C to copy.

<p>Press <kbd>Ctrl</kbd> + <kbd>C</kbd> to copy.</p>
<var>
Represents a variable in mathematical or programming context.

The equation is: x + y = z

<p><var>x</var> + <var>y</var> = <var>z</var></p>
<pre>
Represents preformatted text — whitespace is preserved exactly as written.
function greet(name) {
  return "Hello, " + name + "!";
}
<pre>function greet(name) {
  return "Hello, " + name + "!";
}</pre>
<time>
Represents a specific period in time. The datetime attribute holds the machine-readable value.

The event is on June 21, 2024.

<time datetime="2024-06-21">June 21, 2024</time>
<data>
Links content to a machine-readable translation using the value attribute.

Product: Widget Pro

<data value="sku-00142">Widget Pro</data>

3. Lists

<ul>
Represents an unordered list of items, typically rendered as bullet points.
  • Apples
  • Bananas
  • Cherries
<ul>
  <li>Apples</li>
  <li>Bananas</li>
  <li>Cherries</li>
</ul>
<ol>
Represents an ordered list of items, typically rendered as numbered list.
  1. Mix ingredients
  2. Preheat oven to 180°C
  3. Bake for 30 minutes
<ol>
  <li>Mix ingredients</li>
  <li>Preheat oven to 180°C</li>
  <li>Bake for 30 minutes</li>
</ol>
<li>
Represents a list item. Used inside <ul>, <ol>, or <menu>.
  1. Item starting at 5
  2. Item 6
  3. Item 7
<ol>
  <li value="5">Item starting at 5</li>
  <li>Item 6</li>
</ol>
<dl>, <dt>, <dd>
<dl> is a description list; <dt> is a term; <dd> is the description for that term.
HTML
HyperText Markup Language — the building block of the web.
CSS
Cascading Style Sheets — used to style and layout web pages.
JavaScript
A scripting language enabling interactive web content.
<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language.</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets.</dd>
</dl>

4. Links and Navigation

<a>
Creates a hyperlink to web pages, files, email addresses, phone numbers, or locations within the same page.

MDN Web Docs (opens in new tab)

Jump to Section 1 (in-page anchor)

Send an email

Call us: +1 555 123 4567

Download PDF

<!-- External link -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">
  External Site
</a>

<!-- In-page anchor -->
<a href="#section-id">Jump to section</a>

<!-- Email link -->
<a href="mailto:hello@example.com">Send email</a>

<!-- Phone link -->
<a href="tel:+15551234567">+1 555 123 4567</a>

<!-- Download link -->
<a href="file.pdf" download>Download PDF</a>
<nav> (breadcrumb example)
Navigation can represent breadcrumbs, page links, menus, and more.
  1. Home
  2. ›
  3. Docs
  4. ›
  5. HTML Reference
<nav aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Home</a></li>
    <li><a href="/docs">Docs</a></li>
    <li aria-current="page">HTML Reference</li>
  </ol>
</nav>

5. Images and Media

<img>
Embeds an image. The alt attribute is required for accessibility.
<img
  src="photo.jpg"
  alt="A description of the image"
  width="200"
  height="120"
/>
<figure>, <figcaption>
<figure> groups self-contained content like images, diagrams, or code. <figcaption> provides a caption.
<figure>
  <img src="mountain.jpg" alt="A scenic mountain view" />
  <figcaption>Fig. 1 — A scenic mountain view at dawn.</figcaption>
</figure>
<picture>, <source>
<picture> provides multiple image sources for different screen sizes or formats. The browser picks the best <source>.
<picture>
  <source media="(min-width: 800px)" srcset="wide.webp" />
  <source srcset="narrow.webp" />
  <img src="fallback.jpg" alt="Responsive image" />
</picture>
<audio>
Embeds audio content. Use <source> children for multiple formats and fallback text for unsupported browsers.
<audio controls>
  <source src="audio.mp3" type="audio/mpeg" />
  <source src="audio.ogg" type="audio/ogg" />
  Your browser does not support the audio element.
</audio>
<video>
Embeds video content with optional controls, poster image, and multiple source formats.
<video controls width="320" height="180" poster="thumb.jpg">
  <source src="video.mp4" type="video/mp4" />
  <source src="video.webm" type="video/webm" />
  <track kind="subtitles" srclang="en" label="English" src="subs.vtt" />
  Your browser does not support the video element.
</video>
<track>
Specifies timed text tracks (subtitles, captions, chapters) for <video> and <audio>.

<track> is shown in the <video> example above.

<track
  kind="subtitles"
  srclang="en"
  label="English"
  src="subtitles.vtt"
  default
/>
<map>, <area>
<map> defines an image map (clickable regions). <area> defines each hotspot region.
<img src="map.png" usemap="#mymap" alt="Image map" />
<map name="mymap">
  <area shape="rect" coords="0,0,150,100"
        href="/left" alt="Left Zone" />
  <area shape="circle" coords="200,50,40"
        href="/circle" alt="Circle Zone" />
</map>

6. Embedded Content

<iframe>
Embeds an independent browsing context (another HTML page) inside the current page.
<iframe
  src="https://example.com"
  title="Embedded page"
  width="600"
  height="400"
  sandbox="allow-scripts allow-same-origin"
  loading="lazy"
></iframe>
<embed>
Embeds external content such as PDF documents or interactive plugins.
<embed
  src="document.pdf"
  type="application/pdf"
  width="600"
  height="400"
/>
<object>, <param>
<object> embeds an external resource (PDF, SVG). <param> provides parameters to the object.
<object data="document.pdf" type="application/pdf"
        width="600" height="400">
  <param name="quality" value="high" />
  <p>Fallback: <a href="document.pdf">Download PDF</a></p>
</object>

9. Interactive Elements

<details>, <summary>
<details> creates a disclosure widget. <summary> is the visible heading/toggle. Click to expand/collapse.
What is the <details> element?

The <details> element creates an accordion-style widget. The user can click the <summary> to toggle visibility of additional content.

Another expandable section
  • Item one
  • Item two
  • Item three
<details>
  <summary>Click to expand</summary>
  <p>Hidden content revealed here.</p>
</details>
<dialog>
Represents a dialog box or interactive sub-window. Use the .showModal() JS method to open it.

Dialog Title

This is a native <dialog> element opened with showModal().

Press Esc or click the button below to close.

 
<button type="button"
        onclick="document.getElementById('my-dialog').showModal()">
  Open Dialog
</button>

<dialog id="my-dialog">
  <h2>Dialog Title</h2>
  <p>Content of the dialog.</p>
  <button onclick="document.getElementById('my-dialog').close()">
    Close
  </button>
</dialog>

10. Scripting and Templates

<script>
Embeds or references executable JavaScript code. Use defer or async for external scripts to avoid blocking rendering.

Click to run script:

<!-- Inline script -->
<script>
  console.log("Hello from inline script");
</script>

<!-- External script (deferred) -->
<script src="app.js" defer></script>

<!-- External script (async) -->
<script src="analytics.js" async></script>
<noscript>
Provides fallback content when JavaScript is disabled or unavailable in the browser.
Since JS is enabled in your browser, the <noscript> content below is hidden: 
<noscript>
  <p>Please enable JavaScript to view this content.</p>
</noscript>
<canvas>
Provides a bitmap drawing surface that can be drawn on via the Canvas 2D or WebGL APIs.
<canvas id="myCanvas" width="380" height="160"
        aria-label="Canvas drawing"></canvas>

<script>
  const canvas = document.getElementById('myCanvas');
  const ctx = canvas.getContext('2d');

  // Draw a rectangle
  ctx.fillStyle = '#3b82f6';
  ctx.fillRect(20, 20, 100, 60);

  // Draw a circle
  ctx.beginPath();
  ctx.arc(200, 80, 40, 0, Math.PI * 2);
  ctx.fillStyle = '#f59e0b';
  ctx.fill();
</script>
<svg>
Embeds Scalable Vector Graphics directly in HTML. SVG is resolution-independent and fully styleable with CSS.
<svg width="300" height="120" viewBox="0 0 300 120"
     xmlns="http://www.w3.org/2000/svg"
     aria-label="SVG shapes demo" role="img">
  <title>SVG Demo</title>
  <circle cx="60" cy="60" r="40" fill="#3b82f6" />
  <rect x="115" y="20" width="60" height="60" fill="#f59e0b" />
  <polygon points="240,20 280,100 200,100" fill="#34d399" />
</svg>
<template>
Holds HTML that is not rendered when the page loads. Content is cloned with JavaScript and inserted into the document.
<template id="card-tpl">
  <div class="card">
    <strong class="tpl-title"></strong>
    <p class="tpl-body"></p>
  </div>
</template>

<div id="container"></div>
<button onclick="addCard()">Add Card</button>

<script>
  function addCard() {
    const tpl = document.getElementById('card-tpl');
    const clone = tpl.content.cloneNode(true);
    clone.querySelector('.tpl-title').textContent = 'New Card';
    clone.querySelector('.tpl-body').textContent = 'Cloned from template';
    document.getElementById('container').appendChild(clone);
  }
</script>

11. Ruby and Annotations

<ruby>, <rt>, <rp>
<ruby> wraps the base text and its annotation. <rt> holds the ruby text (pronunciation guide shown above the base). <rp> provides fallback parentheses for browsers that don't support ruby.
漢(かん) 字(じ)   日本語(にほんご) 
<!-- Ruby with fallback parentheses -->
<ruby>
  漢<rp>(</rp><rt>かん</rt><rp>)</rp>
  字<rp>(</rp><rt>じ</rt><rp>)</rp>
</ruby>

<!-- Ruby for a whole word -->
<ruby>
  日本語<rp>(</rp><rt>にほんご</rt><rp>)</rp>
</ruby>

12. Web Components Related Element

<slot>
A placeholder inside a Web Component's shadow DOM that lets users inject their own content. Only meaningful inside a Shadow DOM; shown here as a structural reference. 
<!-- Define a custom element with shadow DOM + slot -->
<script>
class MyCard extends HTMLElement {
  constructor() {
    super();
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = `
      <style>
        .card { border: 2px solid purple; padding: 1rem; border-radius: 8px; }
      </style>
      <div class="card">
        <slot>Default fallback content</slot>
      </div>
    `;
  }
}
customElements.define('my-card', MyCard);
</script>

<!-- Use the custom element — light DOM content fills the slot -->
<my-card>
  <p>This text is projected via <slot></p>
</my-card>

13. Deprecated or Obsolete Elements DEPRECATED

⚠️ The following elements are deprecated or obsolete in HTML5. Do not use them in new projects. Modern CSS or semantic alternatives should be used instead.

<font> DEPRECATED
Used to set font face, color, and size. Replaced by CSS font-family, color, and font-size.
Old-style red text 
<!-- ❌ Deprecated -->
<font color="red" size="4" face="Arial">Text</font>

<!-- ✅ Use CSS instead -->
<p style="color: red; font-size: 1.2rem; font-family: Arial, sans-serif;">Text</p>
<center> DEPRECATED
Horizontally centered its content. Replaced by CSS text-align: center or margin: 0 auto.
Centered text — deprecated
<!-- ❌ Deprecated -->
<center>Centered content</center>

<!-- ✅ Use CSS instead -->
<p style="text-align: center;">Centered content</p>
<big> DEPRECATED
Made text one size larger. Replaced by CSS font-size.
Normal text and bigger text — deprecated 
<!-- ❌ Deprecated -->
<big>Bigger text</big>

<!-- ✅ Use CSS instead -->
<span style="font-size: 1.3em;">Bigger text</span>
<strike> DEPRECATED
Drew a strikethrough line through text. Replaced by <s> or <del>.
Struck-through text — deprecated 
<!-- ❌ Deprecated -->
<strike>Crossed out</strike>

<!-- ✅ Use <s> for no-longer-relevant text -->
<s>No longer relevant</s>

<!-- ✅ Use <del> for editorially deleted text -->
<del>Deleted from document</del>
<tt> DEPRECATED
Rendered text in a monospace "teletype" font. Replaced by <code>, <kbd>, <samp>, or CSS font-family: monospace.
Teletype font — deprecated 
<!-- ❌ Deprecated -->
<tt>Monospace text</tt>

<!-- ✅ Use semantic alternatives -->
<code>inline code</code>
<kbd>keyboard input</kbd>
<samp>program output</samp>
<acronym> DEPRECATED
Was used to mark acronyms. Replaced by <abbr> which handles both abbreviations and acronyms.
WWW — deprecated 
<!-- ❌ Deprecated -->
<acronym title="World Wide Web">WWW</acronym>

<!-- ✅ Use <abbr> instead -->
<abbr title="World Wide Web">WWW</abbr>
<frameset>, <frame>, <noframes> DEPRECATED
Divided the browser window into multiple frames, each loading a separate HTML document. Entirely replaced by <iframe> and modern CSS layout.
These elements cannot be safely demonstrated on a live page. Use <iframe> for embedded documents.
<!-- ❌ Deprecated — do not use -->
<frameset cols="50%,50%">
  <frame src="left.html" />
  <frame src="right.html" />
